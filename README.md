# 🛠️ DevMatch — A Tool for Burned-Out Developers 

We’ve all been there: you open your laptop, you want to code something to build your skillset, but your mind goes completely blank. You spend two hours scrolling through ideas, get overwhelmed, and end up closing your laptop. 

I built **DevMatch** to fix exactly that. It's a no-nonsense, minimalist web app that gives you a random, curated project blueprint based on how much mental energy or experience you have right now. 

## 🌍 Try the Live Web App
See it live in action here: https://github.com/farheenmariam3-dotcom/DevMatch

## 🤔 Why I Built This (The Backstory)
This project was born out of real-world necessity. When tasked with creating a "hobbies project" for my coursework, I realized my favorite hobby is working on my coding skillset—but the hardest part of building projects is figuring out what to build. 

Instead of building a basic calculator or weather app, I decided to build a "meta-project": a system that holds a database of 30 structured project ideas (10 Beginner, 10 Intermediate, 10 Advanced) to help other students break through their brain fog and start coding instantly.

## ✨ Cool Stuff It Does
- **Saves Your Brainpower:** Just pick your current comfort level (Beginner, Intermediate, Advanced) and hit generate. No decision fatigue.
- **Curated Scope:** The ideas aren't just titles; they include a breakdown of *what* the project does so you know exactly what you are building.
- **Dark-Theme UI:** Styled with a clean, slate-dark theme because no developer likes staring at a blinding white screen.

## 💻 Tech Used
I wanted to keep this incredibly clean, lightweight, and fast, so I built it using pure web fundamentals:
- **HTML5:** For the core layout and semantic structure.
- **CSS3:** For the dark theme, responsive layout, and card entry animations.
- **Vanilla JavaScript (ES6):** For the filtering logic, DOM manipulation, and the localized project database array.
